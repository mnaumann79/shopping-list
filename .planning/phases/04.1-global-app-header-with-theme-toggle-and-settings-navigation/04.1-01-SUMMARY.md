## Decisions Made
- `DropdownMenuTrigger` styled directly with Tailwind classes rather than wrapping a `Button asChild` — the project's dropdown-menu is built on `@base-ui/react/menu` which does not expose an `asChild` prop on `Trigger`. Equivalent visual result achieved with `inline-flex items-center justify-center min-h-[44px] min-w-[44px] rounded-md hover:bg-accent`.
- `getInitials` kept as file-local helper function — only used once in AppHeader, no abstraction warranted.
