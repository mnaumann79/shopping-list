## Decisions Made

- Settings page split into server page + client sub-component to keep session fetch server-side while preserving all hooks
- LogoutButton removed since AppHeader absorbed logout functionality in Plan 01 and it had no other callers
- Button asChild replaced with Link + buttonVariants in AppHeader: @base-ui/react does not implement the asChild pattern; discovered during visual verification
- DarkModeToggle text label removed: icon-only is the intended design; title attribute preserves hover accessibility
