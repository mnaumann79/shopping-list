## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (gap-1) |
| sm | 8px | Column gaps within a row (gap-2) |
| md | 16px | Row horizontal padding (px-4) |
| lg | 24px | Section padding, modal content padding (p-6) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Row height: `min-h-[44px]` on the entire row button element — satisfies 44px touch target requirement (established in Phase 4.1). Note: this is not a spacing token; it is a touch target floor.
- Trailing pencil icon button: rendered as `size-7` (28px) via `icon-sm` variant, wrapped in a `min-h-[44px] min-w-[44px]` touch target zone achieved by adding `p-2` (8px) padding. The visible button remains 28px; 28px icon + 8px padding on each side = 44px tap zone. All values are multiples of 4.

## Row Layout Contract

Target viewport: 390px wide mobile.

```
[ checkbox ]  [ name col ]  [ qty col ]  [ store col ]  [ notes col ]  [ ✎ ]
```

Primary focal point: item name (left-anchor, full available width, medium weight, full-opacity foreground).

Column layout: single `flex` row, `items-center`, `min-h-[44px]`, `px-4`, `gap-2`.

| Column | Flex | Max width | Overflow | Content |
|--------|------|-----------|----------|---------|
| Checkbox hit zone | `shrink-0` | 44px | — | Native `<input type="checkbox">` with 44px touch target |
| Name | `flex-1 min-w-0` | unconstrained | `truncate` | Item name, `text-sm font-medium` |
| Quantity | `shrink-0` | 40px | `truncate` | e.g. `x2`, `text-xs text-muted-foreground` — hidden when null/empty |
| Store tag | `shrink-0` | 80px | `truncate` | Single store name in `bg-muted px-2 py-1 rounded text-xs text-muted-foreground` — hidden when no stores assigned; if multiple stores, show first + count badge (e.g. `+1`) |
| Notes preview | `shrink-0` | 72px | `truncate` | First ~20 chars of note, `text-xs text-muted-foreground` — hidden when null/empty |
| Pencil button | `shrink-0` | 44px touch zone | — | `Button` variant=`ghost` size=`icon-sm`, wrapped in 44px hit area |

Column widths are implemented via Tailwind utility classes, not fixed `px` values, so they adapt proportionally. The name column absorbs all remaining space via `flex-1 min-w-0`.

Notes preview truncation: 20 characters maximum visible (enforced via CSS `truncate`, not JS slicing). No tooltip — truncation is decorative context only.

Checked state: wrap all text columns in a single conditional `line-through text-muted-foreground` class applied to the row's text container. Row height stays `min-h-[44px]` regardless of checked state.

## Interaction Contract

| Interaction | Target | Outcome |
|-------------|--------|---------|
| Tap row body (anywhere except pencil icon) | Entire row minus pencil zone | Toggles `isChecked` via `onToggleChecked` — optimistic update |
| Tap pencil icon | 44px touch zone on right edge | Opens edit Dialog modal |
| Tap Save changes in modal | Primary button in DialogFooter | Calls `onUpdate(id, updates)`, closes modal |
| Tap Discard changes in modal | Outline button in DialogFooter | Discards changes, closes modal |
| Tap Delete (Trash2) in modal | Destructive ghost icon button | Calls `onDelete(id)`, shows `toast("Item removed")`, closes modal |
| Tap backdrop / press Escape | Dialog overlay / keyboard | Closes modal, discards changes |

No swipe gestures. No long-press. No drag reorder (deferred).

## Edit Modal Contract

Modal: `DialogContent` (centered, `max-w-[calc(100%-2rem)]` on mobile, `sm:max-w-sm`).

Title: "Edit item" (`DialogTitle`)

Form fields (identical to current inline expanded form):
1. Name (`Input`) — required
2. Quantity (`Input`) — optional, placeholder "Optional quantity"
3. Note (`textarea`) — optional, placeholder "Optional note"
4. Category (`select`) — includes "No category" + "+ New category" option
5. Stores (checkboxes) — one per store; if no stores: link to Settings

Footer (`DialogFooter`):
- Left side: Delete button (`Button` variant=`ghost` size=`icon-sm` className=`text-destructive`) with `Trash2` icon + `sr-only` "Delete"
- Right side: Discard changes (`Button` variant=`outline` size=`sm`) + Save changes (`Button` variant=`default` size=`sm`)

No Sheet variant. The existing Dialog is sufficient. No bottom-anchored positioning — centered Dialog is the choice.

## Accessibility Contract

- Checkbox: native `<input type="checkbox">` with `aria-label={item.name}` on the row's interactive element
- Row tap zone: `<button type="button">` wrapping row body, `aria-label={item.name}`
- Pencil icon button: `aria-label={`Edit ${item.name}`}`
- Delete button: visible icon only; `<span className="sr-only">Delete</span>` required
- Modal: `DialogTitle` provides accessible name; close button has `sr-only` "Close"
- All interactive elements: minimum 44px touch target on 390px viewport
