  <what-built>
Complete Phase 1 authentication and household foundation:
- Sign-up, sign-in, logout (AUTH-01..04)
- Household creation during onboarding (HSHD-01)
- Email invite flow: admin invites by email, new user joins via /accept-invite link (HSHD-02)
- Shareable join link: admin generates link, new/existing user joins via /join?token= (HSHD-03)
- Join by invite email or join link (HSHD-04)
- Household switcher in header for multi-household users
- Household settings page: email invite form, join link with copy, member list with remove
  </what-built>
  <how-to-verify>
Run `npm run dev` (or ensure dev server is running at http://localhost:3000), then test each success criterion:

**SC1 — Sign up and session persistence:**
1. Open http://localhost:3000/sign-up in a fresh browser window (no existing session)
2. Fill in name, email, password → click Sign up
3. Complete onboarding: enter household name (e.g., "Test House") → click Create
4. Verify redirect to http://localhost:3000/dashboard
5. Refresh the page — verify you are still on /dashboard (not redirected to sign-in)
6. Open a new tab to http://localhost:3000/dashboard — verify still authenticated

**SC2 — Logout:**
1. From /dashboard, click Log out
2. Verify redirect to /sign-in
3. Navigate to http://localhost:3000/dashboard directly — verify redirect to /sign-in with ?returnTo=/dashboard

**SC3 — Household creation:**
1. Complete a fresh signup (use a different email)
2. Verify you land on /onboarding (not /dashboard)
3. Try navigating to /dashboard while on /onboarding — verify redirect back to /onboarding
4. Enter household name → Create
5. Verify household name appears in the header switcher dropdown

**SC4 — Email invite:**
1. As admin, go to http://localhost:3000/household/settings
2. Enter an email address you control → Send invite
3. Check that email — click the invite link
4. If logged in as a different account: verify auto-join to household
5. If not logged in: complete sign-up → verify redirect to dashboard and household membership

**SC5 — Shareable join link:**
1. As admin on /household/settings, click Generate join link
2. Copy the generated URL (should be http://localhost:3000/join?token=...)
3. Open the URL in an incognito window (not logged in)
4. Verify redirect to /sign-up?joinToken=...
5. Complete sign-up → verify you land on /dashboard in the correct household
6. Use the same link in another incognito window — verify it still works (multi-use)
7. Verify member list on /household/settings shows both new members

**Manual checks for known edge cases:**
- iOS Safari session: if you have a physical iOS device with a custom domain configured, test login and page refresh. (Skip if no custom domain yet — note it as a pre-production blocker.)
