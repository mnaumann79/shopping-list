# Implementation

## Objective

Add temporary theme preview switches to the settings page. Three palettes are available: Warm & Inviting, Clean & Fresh, and Bold & Playful — each with a dark mode variant. Theme selection is persisted to localStorage and survives refresh. The chosen theme becomes permanent after decision; all preview code is removed.

### Step 2: Add three preview blocks

Added `.warm-preview`, `.clean-preview`, and `.bold-preview` blocks — each with light and dark mode variants — AFTER the existing `:root` and `.dark` blocks.

Key design decisions:
- **Warm & Inviting**: Terracotta primary, sage accent, cream background — Nunito + Fraunces
- **Clean & Fresh**: Fresh green primary, blueberry accent, white background — Poppins + Plus Jakarta Sans
- **Bold & Playful**: Electric coral primary, teal accent, soft lavender secondary — Fredoka + DM Sans

### Step 3: Font stack fix (bug fix during implementation)

**Bug**: Used `var(--font-sans)` as fallback in preview blocks (e.g., `'Nunito', var(--font-sans)`). This created a circular reference — `--font-sans` resolved to just `'Nunito'` with no system font fallbacks, breaking browser font loading.

**Fix**: All preview blocks now use explicit complete stacks:
```css
/* Wrong (circular) */
--font-sans: 'Nunito', var(--font-sans);

/* Correct (explicit) */
--font-sans: 'Nunito', ui-sans-serif, system-ui, sans-serif;
```

### Step 4: Dark mode via compound selectors

Each theme has both light and dark variants using compound selectors:
```css
.warm-preview { /* light mode variables */ }
.warm-preview.dark { /* dark mode variables override light */ }
```

## Task 3: Add three preview toggles to settings with localStorage persistence (implemented)

### Step 1: Read HouseholdSettingsClient.tsx

Read `src/app/(app)/household/settings/_components/HouseholdSettingsClient.tsx` to understand current structure.

### Step 2: Add theme state with lazy localStorage initialization

```tsx
// Theme preview state — persisted to localStorage
const [warmPreview, setWarmPreview] = useState(() => {
  if (typeof window === "undefined") return false;
  return localStorage.getItem("theme-preview") === "warm";
});
const [cleanPreview, setCleanPreview] = useState(() => {
  if (typeof window === "undefined") return false;
  return localStorage.getItem("theme-preview") === "clean";
});
const [boldPreview, setBoldPreview] = useState(() => {
  if (typeof window === "undefined") return false;
  return localStorage.getItem("theme-preview") === "bold";
});
```

### Step 3: Add mount useEffect to apply saved theme

```tsx
// Apply persisted theme on mount
useEffect(() => {
  const saved = localStorage.getItem("theme-preview");
  if (saved === "warm") {
    document.documentElement.classList.add("warm-preview");
  } else if (saved === "clean") {
    document.documentElement.classList.add("clean-preview");
  } else if (saved === "bold") {
    document.documentElement.classList.add("bold-preview");
  }
}, []);
```

### Step 4: Add three toggle switches

Three Switch components in a "Theme Preview" Card section. Each `onCheckedChange`:
1. Updates state
2. Calls `localStorage.setItem("theme-preview", "warm"|"clean"|"bold")` when enabling
3. Calls `localStorage.removeItem("theme-preview")` when disabling
4. Removes competing preview classes from `<html>`
5. Adds/removes its own preview class

Mutually exclusive: enabling one sets the other two to `false`.
