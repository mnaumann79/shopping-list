<task type="auto" tdd="true">
  <name>Task 2: Item member routes — PATCH and DELETE /api/items/[id]</name>
  <files>src/app/api/items/[id]/route.ts</files>
  <behavior>
    - PATCH: updates item fields and atomically replaces all store tags in a single transaction
    - PATCH accepts partial updates: any combination of { name?, quantity?, note?, categoryId?, storeIds? } — only provided fields are updated
    - PATCH store tag replacement: delete all existing itemStores for this item, then insert the new storeIds set (even if storeIds is empty array — clears all tags)
    - DELETE: soft-delete — sets isActive=false, does NOT remove the row from DB
    - DELETE returns 200 + { success: true }
    - Both routes: 404 if item not found within this org
    - Both routes: auth guard + org scope on every WHERE clause
  </behavior>
  <action>
    Create `src/app/api/items/[id]/route.ts`.

    PATCH handler:
    - Auth guard
    - `const { id } = await params` (params is async in Next.js 15)
    - Validate body (all fields optional, same schema as POST but all optional)
    - Build update object: only include fields that are explicitly in the body (use `body.name !== undefined` checks)
    - Always add `updatedAt: new Date()` to the update set
    - If storeIds is in the body (even as empty array), wrap the update in a transaction and replace itemStores
    - If storeIds is NOT in the body, just update the item fields (no junction table touch)
    - Transaction pattern:
      ```typescript
      await db.transaction(async (tx) => {
        const [updated] = await tx.update(items)
          .set({ ...updateFields, updatedAt: new Date() })
          .where(and(eq(items.id, id), eq(items.organizationId, orgId)))
          .returning();
        if (!updated) throw new Error("not_found");
        await tx.delete(itemStores).where(eq(itemStores.itemId, id));
        if (body.storeIds.length > 0) {
          await tx.insert(itemStores).values(body.storeIds.map(sid => ({ itemId: id, storeId: sid })));
        }
      });
      ```
    - Catch "not_found" throw → return 404

    DELETE handler:
    - Auth guard
    - `const { id } = await params`
    - `db.update(items).set({ isActive: false, updatedAt: new Date() }).where(and(eq(items.id, id), eq(items.organizationId, orgId))).returning()`
    - If returning() empty → 404
    - Return 200 + `{ success: true }`

    CRITICAL: Never hard-delete items. isActive=false is the only deletion mechanism. This preserves data for Phase 3 history features.
