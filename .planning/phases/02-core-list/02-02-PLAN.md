    - POST: creates new store with { name } body, validates name is non-empty string (1-100 chars), returns 201 + store object

    - POST returns 400 if name is missing or blank
    - Both return 401 when session missing, 400 when activeOrganizationId is null

    Create `src/app/api/stores/route.ts` with GET and POST handlers.

    GET handler:
    - Auth guard (session + orgId)
    - `db.select().from(stores).where(and(eq(stores.organizationId, orgId), eq(stores.isActive, true))).orderBy(stores.name)`
    - Return `Response.json(storeList, { status: 200 })`

    - Parse + validate body: name must be a non-empty string, trim whitespace, max 100 chars

<task type="auto" tdd="true">
  <name>Task 2: Store member routes — PATCH and DELETE /api/stores/[id]</name>
  <files>src/app/api/stores/[id]/route.ts</files>
  <behavior>
    - PATCH: renames the store — accepts { name } body, validates non-empty 1-100 chars, updates name + updatedAt
    - PATCH returns 404 if store not found within the org (MUST scope by organizationId — never update by id alone)
    - DELETE: hard-deletes the store row — DB cascade via FK onDelete:"cascade" on itemStores.storeId removes all item_stores rows automatically
    - DELETE returns 200 + { success: true } on success
    - Both return 401/400 for missing session/org as established
  </behavior>
  <action>
    Create `src/app/api/stores/[id]/route.ts`.

    Both handlers receive `{ params }: { params: Promise<{ id: string }> }` as second arg (Next.js App Router dynamic segment, params is async in Next.js 15).

    PATCH handler:
    - Auth guard
    - `const { id } = await params`
    - Parse + validate body (name 1-100 chars)
    - `db.update(stores).set({ name: body.name.trim(), updatedAt: new Date() }).where(and(eq(stores.id, id), eq(stores.organizationId, orgId))).returning()`
    - If returning() array is empty → 404 `{ error: "Store not found" }`
    - Else return 200 + updated store

    DELETE handler:
    - Auth guard
    - `const { id } = await params`
    - First check the store belongs to this org: `db.select({ id: stores.id }).from(stores).where(and(eq(stores.id, id), eq(stores.organizationId, orgId)))`
    - If not found → 404
    - `db.delete(stores).where(eq(stores.id, id))` — DB cascade handles itemStores cleanup
    - Return 200 + `{ success: true }`

    Critical: Always include `eq(stores.organizationId, orgId)` in every WHERE clause. Never update/delete by id alone.
  </action>

  </verify>
