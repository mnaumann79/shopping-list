# Requirements: Household Shopping List App

**Defined:** 2026-03-10
**Core Value:** One shared, always-up-to-date list that everyone in the household can see and edit — no more scattered texts, notes, and paper scraps.

## v1 Requirements

### Authentication

- [x] **AUTH-01**: User can sign up with email and password
- [x] **AUTH-02**: User can log in with email and password
- [x] **AUTH-03**: User session persists across browser refresh
- [x] **AUTH-04**: User can log out from any page

### Household

- [x] **HSHD-01**: User can create a household during onboarding
- [x] **HSHD-02**: Household admin can invite members by email
- [x] **HSHD-03**: Household admin can generate a shareable join link
- [x] **HSHD-04**: User can join a household via invite email or join link

### Stores

- [x] **STOR-01**: User can add a store to the household (e.g., "Costco", "Trader Joe's")
- [x] **STOR-02**: User can rename a store
- [x] **STOR-03**: User can delete a store

### Items

- [x] **ITEM-01**: User can add an item with a name, optional quantity, and optional note
- [x] **ITEM-02**: User can edit an item's name, quantity, note, category, and store tags
- [x] **ITEM-03**: User can delete an item
- [x] **ITEM-04**: User can check off an item during a shopping trip
- [x] **ITEM-05**: User can uncheck a checked item
- [x] **ITEM-06**: User can clear all checked items from the list at once

### Categories

- [x] **CAT-01**: Household list has a default set of grocery categories (produce, dairy, bakery, meat, frozen, pantry, beverages, household, personal care, other)
- [x] **CAT-02**: User can create a custom category
- [x] **CAT-03**: User can assign an item to a category when adding or editing

### Organization

- [x] **ORG-01**: User can view items grouped by category / aisle
- [x] **ORG-02**: User can filter the list to show only items tagged to a selected store
- [x] **ORG-03**: User can sort items alphabetically (A–Z)
- [x] **ORG-04**: User can sort items by store

## v2 Requirements

### Authentication

- **AUTH-V2-01**: Magic link login (passwordless)
- **AUTH-V2-02**: OAuth login (Google, Apple)

### Items

- **ITEM-V2-01**: Item history — checked-off items saved for re-adding next week
- **ITEM-V2-02**: Re-add item from history with one tap
- **ITEM-V2-03**: Barcode scanning to add items
- **ITEM-V2-04**: Voice input to add items

### Organization

- **ORG-V2-01**: Custom / manual drag-to-reorder items
- **ORG-V2-02**: Auto-categorization from item name

### Categories

- **CAT-V2-01**: User can rename a category
- **CAT-V2-02**: User can delete a category

## Out of Scope

| Feature | Reason |
|---------|--------|
| Real-time live sync (WebSockets) | Household scale (2–6 users) doesn't justify infrastructure; polling sufficient |
| Native mobile app | Web-first; mobile-responsive browser covers the use case |
| Who added each item | Not a priority for v1 |
| Recipe integration | Separate product surface; scope trap per research |
| Price tracking | Scope trap; adds complexity without core value |
| Offline PWA support | Architectural complexity best added after core is stable |
